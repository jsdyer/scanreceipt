How to read this

Daily GitHub Actions captures visit Rack Expiry, Radar Scope and Hotspot Ledger in a fresh desktop Chromium browser. Our own screenshots and sanitized network responses are archived here; no urlscan database is copied. Manual captures use the same archive. The desk shows the newest 30 receipts; older captures remain in the observation diary. The first day establishes a baseline, then same-page comparisons accumulate. Screenshot links retain the original capture. A separate owner-only urlscan workflow submits one allowlisted public page using the saved API key and returns provider links. Public visitors can use urlscan directly and import the full public Result API JSON locally.

Coverage and privacy

Filters and imports run in your browser. No pasted evidence is uploaded. The page fetches saved data from this site. Source links contact their named providers when opened. The CoolCode counter records aggregate opens, excluding input and filter values.
